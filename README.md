# Shreya Garg — Cosmic Portfolio

A responsive, dark-cinematic portfolio inspired by the supplied six reference screens. It includes Home, About, Projects, Skills, Experience, and Contact. The separate Resume page is intentionally omitted.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Notes
- The anime-inspired character artwork appears only on the Home page.
- Other pages use CSS-generated star fields, orbital graphics, and abstract illustrations—no character image.
- The header theme toggle switches between dark and light themes.
- Navigation scrolls to each page section; thin section dividers separate them visually.
- The contact form opens the visitor's default email app with the message prefilled. Add a real email address to the `mailto:` target in `app/page.tsx` to route messages directly.
- Update project URLs, contact details, and metrics as needed before publishing.
